# DS Lab Programs

This repository contains programs and implementations for the **Data Structures (DS) Lab**.

## Programs Included

- Addition of two numbers
- Array operations
- Bubble Sort
- Circular Queue
- Disjoint Set
- Grading program
- Linear Search
- Merge Sort
- Odd/Even checking
- Queue
- Set operations
- Set Input
- Singly Linked List
- Singly Linked Stack
- Stack
- Breadth First Search (BFS)

## Language

All programs in this repository are written in **C**.

## Repository Structure

| File | Description |
|------|-------------|
| `add.c` | Addition program |
| `array.c` | Array operations |
| `bubblesort.c` | Bubble Sort |
| `circularqueue.c` | Circular Queue |
| `disjoint.c` | Disjoint Set |
| `grade.c` | Grade calculation |
| `linear.c` | Linear Search |
| `merge.c` | Merge Sort |

| `queue.c` | Queue implementation |
| `set.c` | Set operations |

| `singly_linked_list.c` | Singly Linked List |
| `singly_linked_stack.c` | Stack using Linked List |
